# Tema Integrador 2 - TI Verde - GreenCheck

## Objetivo Geral

Planejar, projetar, modelar, codificar e publicar uma aplicação web ou mobile dinâmica (com banco de dados ativo e operações de persistência) focada em sustentabilidade, logística reversa, conscientização ambiental ou economia circular para um parceiro comunitário (cooperativas de catadores, ONGs ecológicas, hortas comunitárias, escolas ou comércios locais). A atividade visa integrar o desenvolvimento fullstack contemporâneo com a responsabilidade socioambiental corporativa da tecnologia da informação (TI Verde). 

### Objetivo do Projeto

O objetivo do GreenCheck é coletar informações sobre as empresas parceiras e fazer um ranking entre elas, sendo o objetivo: informar qual delas é a mais, tecnológicamente, ecológica. Empresas que não derem à autorização para o uso do seu nome oficialmente, ficarâo no anônimato. 


### Tecnologias Utilizadas

- HTML
- TailwindCSS
- JavaScript (Inline)
- Github pages - Deploy
- Supabase - Banco de Dados
